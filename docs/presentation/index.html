The product

What SENTINEL is

A local-first surveillance control plane that keeps video ownership explicit.

One ingest per camera

One authenticated RTSP/TCP session feeds every downstream feature.

Record, view, detect

Original media for recording; LiveKit/WebRTC for viewing; sampled independent detection.

Operate with evidence

Bounded queues, lifecycle state, reconciliation, metrics, audit and failure isolation.
